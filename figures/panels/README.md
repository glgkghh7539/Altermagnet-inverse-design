# `Figures_R1/` — every code-generated figure panel, named as the manuscript names it

One folder, one file per panel. The name is the manuscript designation with the panel
letters in parentheses: a file holding several panels carries the range, a file holding one
carries that letter.

Everything here is regenerated by

```bash
python deposit/figures/make_all_figures.py
```

and copied in unchanged — each file was checksum-verified against the generator's output.

## `composed/`

The published composite figures, rebuilt from the panels above plus the crystal-structure
images, by

```bash
python deposit/figures/compose_figures.py
```

| File | What it is |
|---|---|
| `Fig3.pdf` | `Fig3(a-c)` beside the CuO and FeSi band panels, each under its structure |
| `Fig4.pdf` | `Fig4(a)` over `Fig4(b)`, beside `Fig4(c-d)` under the VO and CrSb structures |
| `Fig5.pdf` | the FeS and NiS structures and their descriptor values over `Fig5(a-b)` |
| `SI_5.pdf` | the same for CoO and CrS |
| `SI_6.pdf` | the same for CoS and FeAs |

Each is at the published page size. The plotted panels go in as vector — text stays text —
and only the fatbands and the structure images are bitmaps, at 333–509 ppi. `*_preview.png`
beside each is a 150 dpi look at it, not for submission.

Fig. 3 and Fig. 4 are **not** at the published layout: their panels were enlarged and their
gutters tightened for the revision. Fig. 5, SI S5 and SI S6 reproduce the published layout
point for point.

## Formats

PDF and PNG for everything the maintained code draws. The fatbands are PNG only — the
notebook that makes them was deposited as it was run, and it writes PNG.

PNG resolution is 800 dpi (Fig. 2, 1000 dpi); in the PDFs the text, axes and lines are
vector and only the `rasterized=True` point clouds are bitmaps, at 400 dpi. All of it is
set in Times New Roman with Computer Modern mathematics, matching the published figures.

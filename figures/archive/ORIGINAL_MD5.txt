# One deliberate change, made after the checksums above were taken.
#
# plotfat_original.ipynb set its colorbar labels with rotation=270:
#
#     cbar1.set_label('spin-up', fontsize=25, rotation=270, labelpad=22)
#
# At 270 the text reads top-to-bottom, so beside the colorbar numbers it comes out
# upside down and against the direction of the y-axis label opposite it. Every other
# colorbar in this deposit leaves rotation at matplotlib's default 90. The published
# Fig. 5 carries the same upside-down labels; this is the one thing about those panels
# that is corrected here rather than reproduced.
#
# 16 set_label calls were changed, rotation 270 -> 90. labelpad moved with them: it is
# measured to the text anchor and the two rotations anchor opposite ends of the box, so
# at equal pad the 90 label sits one font size further out. Measured on a test colorbar,
# (270, pad 22) puts the label 3.4 px inside the tick numbers and (90, pad 0) exactly on
# them - a shift of one font size in points. Each pad became pad - fontsize + 4, so
# 22 -> 1 at 25 pt type and 25 -> 9 at 20 pt.
#
# Nothing else in the notebook was touched.
#
